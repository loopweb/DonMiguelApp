# Don Miguel App

Official web app for **Don Miguel de Cabarete**.

## Technology

- ASP.NET Core 8
- YouTube Data API v3
- Progressive Web App (PWA)
- Responsive web interface
- Render deployment via Docker

## Configuration

The YouTube API key is not stored in this repository.

For deployment on Render, configure the API key as an environment variable / secret instead of committing it to GitHub.

## Deployment

The repository includes the Docker and Render configuration required to deploy the app on Render.
