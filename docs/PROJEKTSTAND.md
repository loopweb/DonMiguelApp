# Projektstand

## Festgelegt

- Sprache der App: Spanisch
- Hauptnavigation: Inicio, Catálogo, Comunidad, Enlaces
- YouTube-Kanal: `@migflow`
- Startseite: neuestes Video groß, weitere Veröffentlichungen darunter
- Player: innerhalb der App, offizieller YouTube-Embed
- Daten: YouTube Data API v3
- Community: vorläufig als Feed aus Veröffentlichungen, weil Community-Posts nicht regulär über die öffentliche API verfügbar sind

## Noch offen

- endgültige Genre-Playlist-Zuordnung
- sämtliche externen Ziel-URLs
- Logo/Icon/Splashscreen
- Rechtstexte und Hosting
- PWA allein oder zusätzlich Store-App
